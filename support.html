Sonori — Support

Sonori interprets lectures, talks, and web media in real time: it shows live

subtitles and speaks the translation over the original audio.

Questions or problems: developer@1xp.com

Getting started

Sonori has no account and no subscription. It uses Google's Gemini API with a

key you provide, so your audio goes from your device straight to Google.

1. Open Settings inside the app.

2. Tap Get a free key — this opens Google AI Studio, where you can create a

Gemini API key in a few seconds.

3. Paste the key into the API Key field.

4. Pick a source and a target language, then start listening.

Common questions

I hear an echo, or the translation talks over itself.

Use earphones. When the speaker plays the translation out loud, the microphone

picks it up again. Earphones remove the loop entirely.

Nothing is transcribed.

Check that the API key is entered and that microphone permission is granted in

iOS Settings. If the key was revoked or its quota is exhausted, Google rejects

the connection and the app shows an error.

Can I use it without an internet connection?

No. Translation happens in Google's Gemini API, so a network connection is

required.

Does it work on Apple Watch?

Yes. Pair the Watch app to hear the translation on your wrist and read the

subtitles there. Settings and the key sync directly from the iPhone to the

Watch.

Which languages are supported?

77 languages, listed in the app's language picker.

What does it cost?

The app is free. You pay Google directly for the Gemini API usage under your own

key. The app shows a running cost estimate while a session is active.

Privacy

We run no servers and collect nothing about you. Your API key is stored

encrypted on your device. See the privacy policy.
