소노리 — API 키는 어디로 가나요

소노리에는 서버가 없습니다. 여러분이 넣은 Gemini API 키는 이 기기에만 저장되고, 통역하는 동안 Google 의 Gemini API 로만 직접 전송됩니다. 개발자는 키를 받을 수도, 볼 수도 없습니다.

확인할 수 있는 사실

  • 저장 위치 — iOS: Keychain(암호화). Android: Android Keystore 의 하드웨어 보호 키로 AES-256/GCM 암호화, 앱 전용 저장소. 클라우드 백업에서 제외됩니다.
  • 전송 목적지 — 앱이 여는 네트워크 연결은 두 곳뿐입니다. generativelanguage.googleapis.com (통역, HTTPS/WSS) 과 aistudio.google.com(‘무료 키 받기’ 화면). 키는 첫 번째 연결의 인증 헤더로만 실립니다.
  • 수집·분석 없음 — 애널리틱스·광고·크래시 리포팅 SDK 가 하나도 없습니다. 개발자에게 오는 데이터가 없습니다.
  • 직접 확인 — 네트워크 프록시(Charles, Proxyman, mitmproxy 등)를 기기에 물리면 위 두 호스트 외에는 아무 연결도 없다는 것을 볼 수 있습니다.

키 안전하게 쓰기 — 3단계

우리를 믿지 않아도 안전하도록, 키 자체에 울타리를 치세요.

  • 1. 소노리 전용 키를 만드세요. Google AI Studio 에서 새 키를 만들고 다른 앱·스크립트와 공유하지 마세요. 문제가 생겨도 이 키 하나만 폐기하면 됩니다.
  • 2. 결제를 연결하지 마세요(무료 등급). 무료 등급 프로젝트의 키는 남용되더라도 청구가 발생하지 않습니다. 필요하면 Google Cloud 콘솔에서 키를 Generative Language API 로만 제한하세요.
  • 3. 언제든 폐기하세요. Google AI Studio 에서 키를 삭제하면 그 즉시 어디서도 쓸 수 없습니다. 앱 설정의 ‘키 삭제’는 기기에서 지웁니다.

Sonori — Where your API key goes

Sonori has no servers. The Gemini API key you enter is stored only on this device and is sent only to Google's Gemini API while interpreting. The developer cannot receive or see it.

What you can verify

  • Storage — iOS: the Keychain (encrypted). Android: AES-256/GCM under a hardware-backed Android Keystore key, in app-private storage, excluded from cloud backup.
  • Destinations — the app opens exactly two network connections: generativelanguage.googleapis.com (interpreting, HTTPS/WSS) and aistudio.google.com (the "get a free key" screen). The key travels only as the auth header of the first.
  • No analytics — no analytics, ads, or crash-reporting SDKs. Nothing reaches the developer.
  • Check it yourself — put a network proxy (Charles, Proxyman, mitmproxy) on the device and you will see no connection other than those two hosts.

Using your key safely — 3 steps

  • 1. Make a key just for Sonori in Google AI Studio and don't share it with other apps or scripts. If anything goes wrong, revoking that one key is enough.
  • 2. Don't attach billing (free tier). A free-tier key cannot generate charges even if abused. Optionally restrict it to the Generative Language API in the Google Cloud console.
  • 3. Revoke any time. Deleting the key in Google AI Studio invalidates it everywhere at once; "Delete key" in the app removes it from the device.
