개인정보처리방침 — AI 실시간 통역 (Android)

최종 수정일: 2026-09-11

AI 실시간 통역("이 앱")은 실시간 음성 통역 앱입니다. 이 방침은 여러분의 데이터에 무슨 일이 일어나는지를 설명합니다. 요약하면: 저희는 서버를 운영하지 않고, 여러분에 대해 아무것도 수집하지 않습니다. 번역은 여러분이 직접 발급한 API 키로 Google의 Gemini API가 수행합니다.

만든 사람

이 앱은 개인 개발자가 만들었습니다. 여러분의 콘텐츠를 받는 백엔드 서버를 운영하지 않으며, 계정 시스템이 없습니다.

기기에만 저장되는 것

다음은 여러분의 기기에만 저장되며, 저희에게 전송되지 않습니다.

  • Google Gemini API 키 — 어디로 가는지, 어떻게 확인하는지, 안전하게 쓰는 법: API 키는 어디로 가나요. Android Keystore가 관리하는 키(기기가 지원하면 하드웨어 보호)로 암호화(AES-256/GCM)되어 앱 전용 저장소에 보관됩니다.
  • 앱 설정 — 통역 대상 언어, 통역 음성, 통역 컨텍스트(주제·용어 메모), 출력 경로, 캡처 모드, 화면 유지 여부.
  • 인앱 브라우저의 방문 기록·북마크 — 주소창의 추천 목록을 만들기 위해 기기 내부 저장소에만 보관합니다. 페이지 내용이나 로그인 정보를 따로 수집·전송하지 않으며, 브라우저 쿠키·세션은 안드로이드 WebView가 앱 전용 영역에 관리합니다.

앱을 삭제하면 위 데이터는 함께 사라집니다.

Google(Gemini API)로 전송되는 것

통역을 위해 이 앱은 여러분이 캡처한 오디오와 그로부터 생성된 텍스트를 Google Gemini API로 전송합니다. 인증에는 여러분 자신의 API 키를 사용합니다. 이것은 여러분의 기기와 Google 사이의 직접 연결이며, 저희 서버를 거치지 않습니다.

오디오의 출처는 둘 중 하나입니다.

1. 마이크 모드 — 기기 마이크로 들어오는 소리. 통역 세션이 실행 중일 때만 마이크가 열립니다.

2. 시스템 오디오 모드 — 같은 기기의 다른 앱이 재생 중인 소리. 이 모드는 Android의 화면·오디오 공유 동의를 세션마다 받아야 시작되며, 동의는 저장되지 않아 시작할 때마다 다시 물어봅니다. 이때에도 화면 이미지는 캡처하지 않습니다 — 이 앱은 화면 픽셀을 읽는 코드를 갖고 있지 않습니다. 또한 캡처 대상은 미디어·게임 재생 오디오로 한정되어 있어 통화 음성은 캡처 대상이 아닙니다.

이 데이터는 Google의 개인정보처리방침 및 Gemini API 약관에 따라 Google이 처리합니다.

  • https://policies.google.com/privacy
  • https://ai.google.dev/gemini-api/terms

이 앱은 오디오를 녹음하거나 저장하지 않습니다. 번역을 위해 스트리밍한 뒤 버립니다. 저희는 그 오디오를 받지 않습니다. 화면에 표시되는 자막도 메모리에만 있으며 파일로 남지 않습니다.

선택 기능인 AI 브리프는 여러분이 입력한 주제 키워드를 같은 Gemini API로 보내 (Google 검색 그라운딩과 함께) 용어 정리를 받아옵니다. 이 역시 여러분의 키로 이루어집니다.

그 밖의 네트워크 연결

  • API 키 발급 도우미 — 설정의 "무료 키 받기"를 누르면 Google AI Studio (aistudio.google.com)가 브라우저 탭으로 열립니다. 평범한 브라우저 세션이며, 이 앱은 그 과정에 개입하지 않습니다.

이 앱이 연결하는 곳은 위, Gemini API(generativelanguage.googleapis.com), 그리고 아래 "오류 보고와 사용 통계" 절의 Firebase 서버(*.crashlytics.com, app-measurement.com, firebaseinstallations.googleapis.com)가 전부입니다. 모든 연결은 TLS로 암호화됩니다.

오류 보고와 사용 통계 (Firebase)

앱이 멈추거나 오작동하는 원인을 찾고, 어떤 기능이 실제로 쓰이는지 알기 위해 Google의 Firebase Crashlytics(오류 보고)와 Google Analytics for Firebase(사용 통계)를 사용합니다. 이때 Google 서버로 전송되는 것은 다음이 전부입니다.

  • 오류 발생 시: 스택 트레이스, 앱 버전, 기기 모델과 Android 버전, 오류 직전의 통역 설정 (입력 방식·대상 언어).
  • 사용 통계: 통역 세션의 시작·종료·실패와 그 길이, 입력 방식(마이크/시스템 오디오/브라우저), 대상 언어, 피드백·리뷰 화면을 연 횟수. 여기에 Google Analytics 가 자동으로 붙이는 기본 정보 — 앱 열기·업데이트·화면 전환·사용 시간 같은 기본 이벤트, 기기 모델·OS 버전·앱 버전·언어 설정, 그리고 접속 IP 로 추정한 국가 단위의 대략적 위치 — 가 함께 갑니다. IP 주소 자체는 저장되지 않습니다. 앱 설치마다 무작위로 생성되는 앱 인스턴스 ID가 붙습니다(앱을 삭제하면 사라집니다).

전송되지 않는 것: 오디오, 자막·번역 텍스트, 통역 컨텍스트, Gemini API 키, 이름·이메일 등 개인정보, 광고 ID, 정밀 위치(위치 권한 자체가 없습니다). 광고 목적으로 사용하지 않으며 다른 앱·사이트와 연결해 추적하지 않습니다. 보관 기간은 Google Firebase 정책을 따릅니다(오류 보고 90일, 사용 통계 2개월 — 저희가 설정한 최소값).

피드백 메일

설정의 "피드백 보내기"는 여러분의 메일 앱을 열고 앱 버전·기기 모델·Android 버전을 본문에 미리 채워 넣습니다. 보내기를 누르기 전까지는 아무것도 전송되지 않으며, 보내면 그 메일(보낸 사람 주소와 적으신 내용 포함)이 developer@1xp.com 으로 옵니다. 문의 처리 목적으로만 쓰고, 처리가 끝나면 보관하지 않으며, 다른 곳에 넘기지 않습니다. 삭제를 원하시면 같은 주소로 요청해 주세요.

저희가 하지 않는 것

  • 오디오·자막·설정 등 여러분의 데이터를 저희 쪽으로 수집·저장·전송하지 않습니다.
  • 광고 SDK를 사용하지 않습니다. 위 오류 보고·사용 통계 외의 분석 도구도 없습니다.
  • 앱이나 웹사이트를 넘나들며 여러분을 추적하지 않습니다.
  • 사용자 계정이 없습니다. 로그인도 회원가입도 없습니다.
  • 접근성 서비스를 사용하지 않습니다.
  • 광고 ID·정밀 위치·연락처를 읽지 않습니다.

권한

  • 마이크 — 통역 중일 때만, 통역할 음성을 캡처하기 위해 사용합니다. 녹음하지 않습니다.
  • 알림 — 통역 세션이 실행 중임을 알리는 진행 중 알림을 표시하기 위해 사용합니다. 거부해도 통역은 동작하며, 알림만 보이지 않습니다.
  • 화면·오디오 공유(시스템 오디오 모드) — Android가 세션마다 직접 물어봅니다. 거부하면 시스템 오디오 모드만 사용할 수 없고, 마이크 모드는 그대로 동작합니다.

아동

Privacy Policy — Sonori (Android)

Last updated: 2026-09-11

Sonori ("the App") is a real-time speech interpretation app. The short version: we run no servers and collect nothing about you. Translation is performed by Google's Gemini API using an API key that you provide.

Who we are

The App is developed by an independent developer. We operate no backend servers that receive your content, and there is no account system.

What stays on your device

  • Your Google Gemini API key — where it goes and how to keep it safe: API key safety. Encrypted with AES-256/GCM under an Android Keystore-managed (hardware-backed where supported) key held in the Android Keystore, in app-private storage.
  • App settings: target language, voice, interpreting context notes, output route, capture mode, keep-screen-on.

Uninstalling the App removes all of it.

What is sent to Google (Gemini API)

To translate, the App sends the audio you capture and the resulting text to the Google Gemini API, authenticated with your own API key. This is a direct connection between your device and Google; it does not pass through us.

The audio comes from one of two sources:

1. Microphone mode — the device microphone, open only while a session is running.

2. System audio mode — audio that another app on the same device is playing. This requires Android's own screen-and-audio sharing consent, granted for every session; the consent cannot be cached, so Android asks again each time. Even then, no screen image is captured — the App contains no code that reads screen pixels. Capture is restricted to media and game playback, so call audio is out of scope.

Google processes this data under Google's Privacy Policy and the Gemini API Terms:

  • https://policies.google.com/privacy
  • https://ai.google.dev/gemini-api/terms

The App does not record, store, or retain your audio. It is streamed for translation and discarded. We never receive it. Subtitles exist in memory only and are not written to disk.

The optional AI brief feature sends the topic keywords you type to the same Gemini API (with Google Search grounding), again under your own key.

Other network connections

  • Getting an API key — tapping "get a free key" in Settings opens Google AI Studio (aistudio.google.com) in a browser tab. That is an ordinary browser session.

Those, the Gemini API (generativelanguage.googleapis.com), and the Firebase servers described under "Crash reports and usage statistics" below (*.crashlytics.com, app-measurement.com, firebaseinstallations.googleapis.com) are the only hosts the App connects to. All connections use TLS.

Crash reports and usage statistics (Firebase)

To find out why the App crashes or misbehaves, and which features are actually used, the App uses Google's Firebase Crashlytics (crash reporting) and Google Analytics for Firebase (usage statistics). This is everything that is sent to Google's servers:

  • On a crash: the stack trace, App version, device model and Android version, and the interpreting settings in effect (capture mode, target language).
  • Usage statistics: when an interpreting session starts, ends or fails and how long it ran, the capture mode (microphone / system audio / browser), the target language, and whether the feedback or review screen was opened. Google Analytics adds its automatic basics to these: standard events such as app open, app update, screen changes and time in app; device model, OS version, App version and language setting; and a country-level approximate location inferred from the connecting IP address (the IP address itself is not stored). Everything carries a random app-instance ID generated per installation (it disappears when you uninstall).

Never sent: audio, transcripts or translations, translation context, your Gemini API key, personal information such as name or e-mail, advertising IDs, precise location (there is no location permission). Nothing is used for advertising and nothing is linked across apps or websites. Retention follows Google's Firebase policy (crash reports 90 days, usage statistics 2 months — the minimum we can set).

Feedback e-mail

"Send feedback" in Settings opens your own mail app with the App version, device model and Android version pre-filled in the body. Nothing is sent until you press send; when you do, that message (including your sender address and whatever you wrote) arrives at developer@1xp.com. We use it only to handle your request, do not keep it once the request is closed, and never pass it on. Write to the same address if you want it deleted.

What we do NOT do

  • We do not collect, store, or transmit your audio, transcripts or settings to ourselves.
  • We use no advertising SDKs, and no analytics beyond the crash reporting and usage statistics described above.
  • We do not track you across apps or websites.
  • There are no user accounts.
  • We do not use any accessibility service.
  • We do not read advertising IDs, precise location, or contacts.

Permissions

  • Microphone — used only while you are interpreting, to capture the speech to be translated. Nothing is recorded.
  • Notifications — to show the ongoing notification while a session runs. Denying it does not stop interpretation; only the notification is hidden.
  • Screen and audio sharing (system audio mode) — requested by Android itself, every session. Declining it disables only that mode; microphone mode still works.

Children

The App is not directed to children.

Your choices

  • Remove your API key at any time in Settings ("delete key").
  • Stop a session at any time, from the app or from the ongoing notification.
  • Uninstalling the App deletes everything stored on the device.
  • We hold no data on any server, so there is nothing for us to delete on request. For data sent to Google, see your own Google account settings.
